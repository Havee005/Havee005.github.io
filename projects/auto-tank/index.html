Overview

Auto-tank is an autonomous mobile robot built for indoor navigation. It uses a differential drive, steering by changing the speed of its left and right wheels.

The robot runs on ROS, with separate nodes for each part of the system, so the hardware, sensing and mapping stay modular and easy to debug.

System

  • ROS nodes handle motor commands to the differential drive
  • Wheel encoder data is read and published for odometry
  • LiDAR scans are read and fed to SLAM
  • SLAM builds a map of the space while tracking the robot's position in it
